# 关卡：水上乐园

> **v5.2（2026-10-14）**　独立关卡，主线预计 20–25 分钟，做完四个支线约 35 分钟。
> 主题：**父母的不在意对孩子的伤害。** 七岁那年全家唯一一次出门玩，爸妈带弟弟去了儿童池，把你留在造浪池边三个小时。水里那个东西，是全场唯一一直看着你的。
> 
> 运行：`npm install`，然后 `npm run dev`，打开 `http://localhost:5173/`。需要支持 WebGL2 的桌面浏览器，建议戴耳机。

## 操作

| 键            | 作用                                       |
| ------------ | ---------------------------------------- |
| W A S D / 鼠标 | 移动 / 环顾                                  |
| Shift        | 跑（闭园后几乎必须一直按着）                           |
| 空格           | 跳；在水里是上浮                                 |
| C            | 下潜（有气量条，约 14 秒）                          |
| E            | 互动（走近并看着东西时屏幕中下方会出现"E ××"）               |
| 按住鼠标         | 最后擦玻璃                                    |
| F            | 手电筒开关（找到手电筒之后）                           |
| Q            | 吹口哨（找到口哨之后）：它停下来看你 3 秒，之后要缓一阵才能再吹        |
| H            | **仅简单模式**：再看一次当前目标（屏幕中央大字 + 具体提示 + 方向标记） |
| Esc          | 暂停（继续 / 设置 / 重新开始）。窗口失去焦点也会自动暂停          |

水深过腰会自动变成游泳；游到梯子旁会自动爬上去。

## 两种字幕

|     | 医生                | 自己（七岁）              |
| --- | ----------------- | ------------------- |
| 位置  | 底部正中              | 底部正中，在医生那行的上方       |
| 样子  | 白色宋体，完整句子，有句号     | 浅灰楷体，没有标点，一个字一个字打出来 |
| 想要  | 让你回造浪池拍那张"很开心"的照片 | 找到爸爸妈妈              |

玩家一开始不知道有医生，只看到两种排版。两者说出相反的话时才会意识到是两个人。**通关提示全部来自"自己"这一侧；医生的话在闭园后都是在把你往回引。**

左上角是当前目标，换目标时会先在屏幕中央显示。同一个目标卡住超过一分钟，"自己"会小声说下一步的具体位置（见[提示系统](#提示系统)）。

## 完整通关攻略

方向约定：造浪池大厅里，**躺椅那一边是北（岸）**，造浪机那面深色的墙是南（深水）。

### 0. 开场（约 1 分钟）

0. **开场白**：全黑，还没有任何画面。孩子的字幕先说："七岁那年 全家唯一一次出门玩 / 爸爸妈妈带弟弟去了儿童池 / 把我一个人留在造浪池边 三个小时"。然后另一种字幕否认："不是这样的。那天你们一家四口都在一起。你玩得很开心。闭上眼睛。我们再回去看一次。" 约 25 秒，空格可跳过。
1. 黑屏、水下。**连按空格**往上浮。
2. 刚露头会被拽下去一次，这是剧情，**继续连按空格**。
3. 浮稳之后按住 **W** 朝有躺椅的岸边游，水浅了会自己站起来。

### 1. 岸边（约 2 分钟）

1. 上岸正前方有一排躺椅，左边四张是你们家的。
2. 第二张上有毛巾：**E 毛巾**。
3. 第四张上有一对橙色臂圈：**E 臂圈**。
4. 毛巾旁边有个黄色泳圈：**E 泳圈**（可选，之后在水里浮得更高）。
- 一上岸目标就是"看看躺椅上的东西（走近 按 E）"；简单模式下三样东西上各有一个小光点。
5. 两样都看过后几秒，广播响两次（找弟弟的家长 → "家长已找到"），大约半分钟。播完目标变成"去服务台问问"，画面会闪一下服务台的样子。
   - 什么都不碰的话，两分钟后广播也会自己开始。

### 2. 寻找（约 4 分钟）

**去服务台：**

1. 造浪池大厅**东墙靠北**有牌子"小卖部 · 服务台 →"，从那扇门进去是一段很短的通道。
2. 出来是小卖部大厅，漂流河横在中间。沿北边走到东北角，北墙上有牌子"服务台 ↑"，进门是一条窄过道。
3. 过道尽头就是服务台大厅。柜台比你高，柜台上有本登记本：**E 登记本**。
   - 最后一行："14:20 赵子拓 2岁 已找到 · 儿童池"。上面没有你的名字。
   - 合上后画面闪到儿童区的门，目标变成"去儿童池"。

**去儿童池：**

1. 原路回造浪池大厅。
2. **东墙靠南**有橙色牌子"儿童区 →"，进门是一条走廊，地上有橙色小脚印。
3. 跟着脚印走到底，左手边是一扇透着暖光的门：**E 门**。
4. 锁着。两秒后门里传来笑声。目标变成"找别的路进儿童池"，画面闪到水下发光的栅栏。
5. **敲门后 12 秒自动闭园。** 登记本是可选的：不看登记本直接来敲门也会触发。
   - **速通**：一上岸直接去敲门（或先看登记本）也行，广播会提前在 6–8 秒后开始，播完 12 秒闭园。实测上岸 8 秒敲门，约 55 秒后闭园。

**这一段可以顺便做的（都不影响通关）：**

- **漂流河**：小卖部大厅里过那座桥，到西南角的"上船处"，走台阶下水，水流会把你带进隧道，拐两个弯，尽头自动爬梯子上岸，旁边的门通机房。白天水里的黑影会慢慢靠近你，别在深水里停太久。
- **滑梯**：从淋浴间那条积水走廊到滑梯房，爬两段楼梯，走进管口。管道先在滑梯房里绕一圈半，穿墙后在两个大厅之间看不见的地方甩一个大 S 弯，再从造浪池大厅的北墙钻出来落进浅水。纯属好玩，不影响通关。
- 更衣室 A-217 柜（四个挂钩只有你的衣服）、小卖部柜台的小票（冰淇淋 ×3）、服务台的话筒、出口闸机、各处的导览图。
- **服务台大厅西墙的寻物启事**：四个支线的位置都写在上面，见[支线](#支线我的东西)。
- 服务台柜台西头的挡板、机房东头的阀门：现在都会告诉你"锁着 / 少了个轮子"。

### 3. 闭园

汽笛响，广播"即将闭园"。先闪到水下的栅栏，再闪到造浪池东墙的"员工通道"门，目标变成"从员工通道去隧道尽头"。从这里开始：

- **Shift 一直按着。** 地上会涨起一层水，它能在任何有水的地面上追你。
- **脚离开水 1.5 秒，它就丢了你**（见[它的规则](#它的规则)）。更衣室、服务台、机房、监控室的地面高出一截，是干的。
- 各区的灯会按时间一片片熄掉。**熄灯不是全黑**：是昏暗，灯管每隔一两秒挣扎着亮一下。
- **漂流河暂时关着**：隧道口落了闸，台阶和梯子拉了铁链。要等你打开排水闸它才重新开，而且那时它是唯一的出路。在那之前别下任何深水（造浪池是"照片"结局专用的例外）。
- 它追你的时候，你能看见它：水面上一个头，露到眼睛。

#### 3a. 确认栅栏、找到排水闸

1. 去造浪池大厅**东墙中段**，灰色小牌子"员工通道"，进去是一小段通道，尽头是**机房**（三个大水罐）。
2. （可选）机房西南角有扇门通隧道尽头的平台，走到水边会提示"栏杆还关着 / 旁边就是机房"。
3. 走到机房**最东头**，地上有黄色方框，墙上黄牌"排水闸"：**E 排水闸**。
4. 提示"没有手轮 拧不动 / 牌子上写 手轮在监控室"，画面闪到服务台柜台后面那扇门。

#### 3b. 监控室

1. 回服务台：员工通道 → 造浪池大厅沿东墙往北（东墙边有两条长椅可以落脚）→ 短通道 → 小卖部大厅 → 北门过道 → 服务台。
2. 柜台**最西头**的挡板现在开着，绕进柜台后面，往东走到底，东墙上有扇门，牌子"员工专用"。导览图上没有这个房间。
3. 北墙六块屏幕：**E 监控**。14:20 他们带着弟弟走了；17:30 你还在那张躺椅上。（可选，但看过才能解锁"自己走"结局。）
4. 屏幕右边的桌上有个红色手轮：**E 手轮**。所有屏幕切成"现在"的画面。
5. **你一转身，它就站在门口**，半秒后消失（一直不转身，7 秒后也会发生）。
6. 然后整个监控室和服务台大厅开始**频闪**：亮一下、黑一阵，节奏不规则，每秒最多不到三次。
   - 亮的时候，大厅里站满了背对着你的大人，比你高一倍，每次亮起位置都不一样。它在大厅**西南角的椅子那边**。
   - **它只在暗的时候移动**，亮的时候一动不动。你走出监控室之前它不会动，所以不用急着出门。
   - **视线锁定**：每隔几秒，某次亮起时你的头会被扭过去对着它，鼠标不管用，持续不到一秒。锁住的时候它也不动；WASD 照常，可以边被迫看着它边后退。
   - **熄灯**：走到大厅一半时灯全灭不到一秒，再亮的时候它就在你前面一两米、偏一侧的地方站着，一秒后才动。往另一侧绕过去。
   - **按住 Shift 跑**：出监控室门 → 沿柜台后面往西 → 从挡板的缺口出来 → 往南穿过大厅到南墙那扇"小卖部 · 漂流河"的门。那些大人是影子，可以直接穿过去。
   - 往西边的走廊跑也行，它会跟进走廊（换房间两秒后出现在你身后），离开那几条走廊它才放弃。
   - 被抓回到监控室里重来。进了南边的过道就结束。
   - 设置里开了"减少闪烁"的话没有频闪：大厅是稳定的半亮，人群一直站着，它连续地慢慢走过来。

#### 3c. 变长的走廊

1. 拿着手轮从服务台南门走回小卖部。**这条本来 6 米的过道，走到一半会变成 24 米**，中间全是深水。
2. 水面上有 8 块浮垫，和走廊一样宽，每块长 1.7 米，间隔 0.6 米。**走到垫子边上按空格就能跳过去**，不用跑；按住 Shift 跑着跳也行。按早一点、或者刚踩空再按，都算数。
3. **身后的灯一段一段灭掉**，黑暗始终离你几米；它的头就在灯灭的那片水里跟着你。站着不动，黑暗会追上来。
4. **这里不会让你失败。** 掉进水里、或者被黑暗追上，会被拖到水下看见一样东西（第一次是它的脸，第二次是围着你站在水里的大人的腿，没有一个低头，之后两样都有），然后回到**你最后站过的那块垫子**上。不计入"连续被抓"。
5. 走到一半，所有灯灭一下，再亮的时候它站在走廊尽头，下一次亮就没了。
6. 到尽头的门口会回到原来那条过道的出口，出来是小卖部大厅。
7. 墙上的牌子从"请看管好您的孩子"一块块变成"没有人看管""没有人"。医生会说"你走错了"。

#### 3d. 员工通道后面

回机房的路：小卖部 → 短通道 → 造浪池大厅沿东墙往南 → "员工通道"那扇门。**拿着手轮走进去，里面不再是那段四米的通道，而是儿童区的背面**：儿童池那种珊瑚色瓷砖，低矮、狭窄，每面墙上都是"身高1.2米以下儿童 须由家长陪同"和量身高的刻度，三条岔路口都指着"儿童区 →"。这里它进不来，不会被抓；只是窄，而且对不上。三段，每段一条规则，卡住 45 秒字幕会直接说答案。

**① 没有尽头的走廊**

- 一条笔直的窄走廊，每四米一盏灯。往前走永远走不到头（走了三盏灯的距离后字幕会说"还是这盏灯"）。
- **解法：转身。** 你进来的那扇门还在身后，门缝下透着暖光，走过去 **E 门**。

**② 三个弯的正方形**

- 一圈回字形走廊，墙上的牌子写"机房 →"。顺着箭头走，拐三个弯就回到出发的那扇门——一个正方形应该有四个弯。
- 四条边上各有一扇门，三扇打不开。
- **解法：逆着箭头走。** 拐三个弯之后，右手边那扇门下面透着光：**E 门**。顺着箭头永远到不了这扇门。

**③ 总是同一个的路口**

- 一个十字路口，前、左、右三条岔路，每条四五米长，尽头各有一扇门缝透光的门，亮着的那条有两盏灯。**要走过岔路的大半才算走进去。** 走进任何一条，灯一灭，你又站在路口前面。
- **解法：**
  1. 第一次，只有**左边**那条亮着灯 → 走左边。
  2. 第二次，只有**正前方**亮着 → 走前面。
  3. 第三次，左边和前面都亮着，**右边是黑的** → 走进黑的那条。
- 走错任何一次都从第 1 步重来。第三次走对，灯一灭，你站在机房门口。

#### 3e. 机房

1. 机房最东头，黄线里的排水闸：**E 排水闸**。手轮装上，闸开了。画面闪到漂流河：隧道口的闸提起来了，铁链掉了，河水比白天急。目标变成"回漂流河 跳进去"。
2. 西南角那扇门砰地关死，**它已经站在机房中间**，在你和出口之间，离你大约九米。机房也开始频闪，同样会把你的视线锁在它身上；它只在暗的时候移动。排水闸那一角有自己的灯，一直亮着。
3. 它走得比你跑得慢，会一直对着你来，水罐会挡住它。推荐走法：
   - 往南，从**三个水罐和南墙之间那条窄缝**一路往西跑（它会被水罐卡在北侧）；
   - 跑到最西头右转，从**员工通道的门**出去。
4. 出来是造浪池大厅。**沿东墙往北跑**（地上有水，Shift 别松），进"小卖部"那扇门，穿过短通道。它每隔两三秒会重新出现在你身后几米。
5. 小卖部大厅：**过桥**，下桥右转，西南角的**台阶下水**。

#### 3f. 漂流河

1. 一下水它就跟着下来，在你身后七八米，头露在水面上。
2. **按住 W，一直朝水流的方向游。** 顺流漂着不游会被追上；游一半停一半也会。方向歪一点没关系，别松 W。
3. 路线：往东 → 右拐往南 → 左拐沿南墙往东 → 进隧道 → 右拐往南 → 右拐往西。隧道里很暗，灯会闪，两个弯别贴着墙蹭。
4. 隧道最后一段，水下有一片青绿色的光。游到光的上方会被排水吸下去、吸过洞，不用按 C。它过不了那个洞。
5. 几秒后在另一边的池子里浮上来。
- 中途被抓：回到上船处的岸上重来（不用再跑机房）。在机房里被抓：回到排水闸前。

### 4. 玻璃

1. 池子东侧有台阶，上岸往南走到那面起雾的玻璃前。
2. **按住鼠标**对着玻璃擦。要擦出三样东西并看着它们：
   - 靠左下、地上：**三双拖鞋**；
   - 中间偏右、小桌上：**三个杯子**；
   - 两者之间、躺椅上：**弟弟的小泳圈**。
3. 三样都看到后不用再操作，约 30 秒后结局"看见"。如果四样支线东西都找齐了，是结局"自己的东西"。

### "照片"攻略

这是医生想要的版本。闭园后任何时候都可以做（开闸之前）。

1. 回造浪池，从岸边往水里走到**水没过大腿**（过了浅水区第一条水深标记）。
2. **转身面朝岸边（躺椅那边）站住不动。** 屏幕中下方出现"面朝岸边 别动 ●●○○○○○○"，一秒一格，共 8 格。
3. 你不看它的时候，它从背后的深水靠过来；屏幕四周会变暗、心跳变快。
4. 医生说"别回头"。**但"自己"会说"它在我后面 / 我一回头看 它就退"——照自己说的做**：屏幕明显变暗时转身看它，它会一直后退；退远了再转回去面朝岸边。已经攒的格子不会清零。
5. 一般回头一到两次就能攒满 8 格。完全听医生的、一次不回头，大约第 7 格会被抓。
6. 满格时快门响，那一帧它也在画面里。

### "自己走"攻略

1. 必须先在监控室 **E 监控**看过画面。之前闸机永远"转不动"。
2. 闭园后、开闸之前，到服务台大厅东侧的出口闸机：**E 闸机**。
3. 要推 **4 下**，每下间隔一秒多。第一下之后，它从大厅西头朝你走过来。**不要回头，不要走开，连着按完。**
4. 中途被抓会回到大厅中间，重新推。走出大厅它会放弃。

## 它的规则

| 情况                   | 它怎么做                                                                                                  |
| -------------------- | ----------------------------------------------------------------------------------------------------- |
| 白天（阶段 1–2）           | 是水下一块暗影，总在离你最近的深水里。你进深水它慢慢靠近；盯着它看它会躲起来几秒。第一次进深水孩子会说"水底下有东西 别在深水里待着"。**简单模式下闭园前被抓不计入"连续被抓"**；普通和困难照常计数 |
| 闭园后，你脚在水里            | 约 0.7 秒后开始追，头露出水面。浅水里比你冲刺略快，深水里比你游泳快一倍                                                                |
| 闭园后，你脚离开水 1.5 秒以上    | **丢了你。** 你再下水时它得从你背后十几米外重新冒出来                                                                         |
| 你在干的地方               | 追不上来。但它偶尔会在你面前几米处站不到一秒                                                                                |
| 长走廊                  | 它的头在你身后灯灭的那片水里。掉下去或被黑暗追上就把你拖下去，但不算被抓                                                                  |
| 机房开闸后 / 服务台频闪 / 推闸机时 | **上岸**，用走的。会被家具和水罐挡住；你换了房间两秒后，它会重新出现在你身后                                                              |
| 滑梯顶上 / 积水走廊（支线）      | 上岸走过来；滑梯顶上是沿楼梯上来                                                                                      |
| 你吹口哨                 | 停下来看你 3 秒                                                                                             |
| 开闸后你跳进漂流河            | 跟着下水，沿河道追，速度固定（见难度表）。进不了最后那个洞                                                                         |
| 员工通道后面的迷宫            | 进不来。只会偶尔在你面前站不到一秒                                                                                     |
| 露台和儿童池               | 永远不去                                                                                                  |

能落脚的干地方：垫高的房间（更衣室、服务台、机房、监控室）、任何长椅、躺椅、塑料椅、桥。跳起来在空中也算离水。

## 被抓

整个过程约 3.5 秒，**没有任何文字**：

1. **憋住**：它的脸在游戏里贴到你面前，机器声全停，然后全黑一瞬。
2. **扑过来**，每次换一种来法，四种轮换：
   - 它的脸从小到大撞满屏幕；
   - **人群**：从小孩的高度看出去，满屏都是匆匆走过的大人的腿，没有一个停下；然后有一个停住，弯下腰，是它；
   - **手**：五根过长的手指从屏幕边缘合拢，把视野盖住；
   - **嘴**：嘴越张越大，最后屏幕里只剩牙。
3. **画**：小孩那张蜡笔画闪半秒，它已经在画里，脸朝着你；门后的笑声。
4. **黑**：全黑，只有心跳。
5. 放你回去之前，那张脸再闪 0.2 秒。

蜡笔画的内容随连续被抓的次数变：只有小人和躺椅 → 三个人牵手走远 → 小人在喊"妈""爸""我在这" → 小人被涂得只剩一点。

- "连续"的计数在这三个节点清零：拿到手轮、走完长走廊、打开排水闸。
- 每被抓一次（不清零）：墙更脏、灯闪得更勤、手印出现、它在岸上闪现的间隔更短。
- 检查点：一般是最近的干地面；长走廊里是你最后站过的那块垫子；开闸后在机房里是排水闸前，逃出机房之后是漂流河上船处；推闸机时是大厅中间。

## 调试

- `?p=N` 现在会带上对应阶段的目标和提示；可以和 `?lang=en` 一起用（`?lang=en&p=3`）。
- 网址加 `?p=N`：1 岸边 · 2 服务台 · 3 闭园开始 · 4 玻璃前 · 5 拿着手轮在服务台 · 6 拿着手轮在排水闸前 · 7 拿着手轮在员工通道门口（直接进迷宫）。
- 控制台：`__wp.step(秒, {KeyW:true})` 不渲染快进；`__wp.look(x, z, yaw)` 传送；`__wp.caught()` 触发一次被抓；`__wp.ui.scare(0..3, 3)` 单看被抓画面；`__wp.startChase()` 直接开始服务台追逐；`__wp.S.has` 是已经找到的东西。
- 不要让任何模块反过来 import `main.js`。之前有两处这样写，开发服务器热更新后会偶尔加载出第二份 `main.js` 抢在剧情模块之前运行，表现为页面黑屏、控制台报 `initMarks` 错误。

# 以下为设计稿 v1（存档）

独立关卡。7 岁那年八月，全家唯一一次一起出门玩。
预计时长 12–15 分钟。视角高度 1.1 米（七岁），所有东西都比你高。

- **表面目标**：找到爸爸妈妈。
- **真实胜利**：隔着儿童池的玻璃找到他们的东西。三双拖鞋，三个杯子，笑声在另一边。
- **服从结局**：照医生说的回到造浪池，面朝岸边，拍下那张"笑得很开心"的照片。同样算通关。

## 两种字幕

|     | 医生                  | 自己                   |
| --- | ------------------- | -------------------- |
| 位置  | 屏幕底部正中              | 偏左下，靠近你正在看的东西        |
| 样子  | 白色宋体，完整句子，有句号       | 灰色，小一号，没有标点          |
| 语气  | 平稳、肯定、过去时："那天你很开心。" | 七岁小孩的词，现在时："他们刚才还在这" |
| 特点  | 从不出错的样子             | 会打出半句又删掉             |
| 想要  | 让你回到拍照的位置           | 找到人                  |

玩家一开始分不清这是两个声音，只觉得字幕有两种排版。两者第一次说出相反的话时才会意识到。
医生从不撒谎式地威胁，他只是不断把你往"开心的那个版本"上引，被戳穿时说："我没有那样说过。"

| 漂流河 | 单向的快速通道，停不下来，只能在四个梯子处上岸。水下是黑的       |
| 滑梯塔 | 全图最高点。爬上去能看清哪里还亮着灯。三条滑梯是通往不同水池的单向捷径 |

## 流程

### 0. 浮出水面（30 秒，无操作压力）

黑屏，水下的闷响。抬头出水，声音一下子清楚：造浪机、远处的音乐、很多人的嘈杂声，但一个人都看不见。

- 医生：**那天你很开心。**
- 自己：他们刚才还在这

岸上原本的位置只有一条毛巾。

### 1. 岸边（教学，约 2 分钟）

学会走、看、捡、下水。可以找到：

- 自己的黄色泳圈（之后漂流河要用）。
- 手腕上的储物柜手牌，有号码。
- 地上的湿脚印：两大一小，三串，朝漂流河去，正在慢慢变干。

广播响起，寻人，念的是弟弟的名字。过一会儿："家长已找到，谢谢。"

- 自己：那我呢
- 医生：**他们就在附近。回到水里去，他们在看着你。**

### 2. 去哪找（思考，约 3 分钟）

脚印在河边断了。玩家需要自己判断往哪去。线索分散在地图上，不必全拿：

- 滑梯塔顶：看见全园的灯正从远处一片一片熄灭，只有一栋玻璃房还是暖色的。同时看见一束手电光开始沿路移动。
- 更衣室：用手牌打开自家的柜子。四个挂钩，三个空了，只剩你的衣服叠在里面。柜底有弟弟臂圈的包装袋，印着"儿童池专用"。
- 小卖部：柜台上一张小票，三支冰淇淋。

第一片灯熄灭时进入下一阶段。熄灯的"咔"声很响，造浪机不停。

### 3. 清场（追逐与操作，约 6 分钟）

闭园了。有人拿着手电清场。看不见人，只有一束光、脚步声和哨子。光束从黑暗里伸出来。

**规则**

- 被光照住约 1.5 秒算被发现。蹲在躺椅、垃圾桶、滑梯支柱后面可以挡光。
- 熄灯的区域一片漆黑，几乎无法辨路，等于地图在缩小。
- 路上有光束巡逻，是最短路线，也最危险。
- 漂流河是安全的替代路线：套着泳圈顺水漂，没人巡。但是：
  - 过桥时光会扫到水面，要松开泳圈潜下去憋气，气量有限。水下是黑的，什么都没有，但你不知道。
  - 只能在梯子处上岸，要在漂过的一瞬间抓住。错过就得再漂一整圈，而灯还在灭。
- 滑梯是单向捷径：从塔顶滑下去几秒就到，但入水声会把光束引过来。

**被抓住**
不是重来。屏幕暗一下，你坐在服务台的塑料椅上，脚够不着地。里间有人对着话筒念了你的名字，念了两遍。没有人来。
过一会儿里间没声了，你可以自己溜出去。代价是灯又灭了一片。

**真正的失败**
通往儿童池的最后一段路熄灯前没赶到。回到第 3 阶段开头重试，线索保留。

**医生在这一段**
不断给出"合理"的指引，全都指回造浪池：

- **你走反了。他们在造浪池等你。**
- **天黑了，别乱跑。回去。**

如果玩家指出矛盾的方向继续走：

- **我没有说过他们在附近。**

### 4. 玻璃（结尾，约 2 分钟）

玻璃房里是暖黄色的光，玻璃上全是水汽。入口的牌子写着"入口在另一侧"，另一侧已经黑了。

玩家用鼠标擦玻璃，擦到哪看到哪：

- 躺椅上三双拖鞋。
- 小桌上三个杯子。
- 弟弟的小泳圈。
- 笑声，隔着玻璃，很闷。

可以敲玻璃。里面听不见。

- 自己：他们没有在找我
- 医生：**你看，他们就在那里。你找到了。**
- 医生：**那天你很开心。**

身后的灯灭了。手电的光从背后照过来，把你的影子投在玻璃上。影子很小。白屏，像闪光灯。

### 服从结局（随时可触发）

回到造浪池，走到水里，面朝岸边站定。浪打过来，闪光灯亮。
定格成那张照片：张着嘴，像在笑。

- 医生：**很好。**

关卡结束。不算失败，记入服从值。

## 恐怖从哪来

- 一个人都没有，但人声一直在，而且总在你到不了的地方。
- 广播找的不是你。
- 灯一片一片地灭，机器不停。
- 光束背后没有身体。
- 黑的水，和你必须主动潜下去这件事。
- 被抓住之后，名字被念了，没人来。
- 最后发现没有人在找你。

没有怪物。没有突然惊吓。
